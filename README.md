# 抽样拍照 · 取证归档

面向产品监督抽查现场取证的手机 App（PWA）。按**抽查批次**管理六类照片，离线拍摄、自动加水印、按批次导出归档，与项目里的样品确认书、原始记录流程配套使用。

## 六类照片

| 序号 | 类别 | 默认要求 |
|---|---|---|
| 01 | 企业抽样（营业执照） | 至少 1 张 |
| 02 | 购物票据（发票） | 至少 1 张 |
| 03 | 现场取样（样品照片） | 至少 1 张 |
| 04 | 现场封样（封样） | 至少 1 张 |
| 05 | 抽样单和签字 | 至少 1 张 |
| 06 | 样品运输 | 至少 1 张 |

每类**最少 1 张、最多 10 张**；最低张数可在设置里调（1–10）。某类拍满 10 张后，需要先删除才能继续拍。

## 主要功能

- **批次管理**：从 Excel 生成的 CSV 批量导入，或手动新建；抽样人逐批可改，默认值来自设置。
- **拍照水印**：批次号、照片类别、拍摄时间、GPS 经纬度直接烧入图片像素。无定位时显示“GPS 未获取”。
- **离线可用**：照片存在手机浏览器本地（IndexedDB），断网、锁屏、杀进程都不丢；装一次后离线打开。
- **进度清单**：六类照片逐项计数，缺哪类一眼看到。
- **提交锁定**：拍齐后提交，照片只读，防止误删误改；可解锁。
- **导出 ZIP**：按 `批次号/01_类别/001_时间.jpg` 归档，内含：
  - `照片清单.csv`（时间、GPS、尺寸、SHA-256、备注）
  - `批次信息.csv`
  - `照片汇总.html`（电脑打开可直接打印或另存 PDF）
- **防篡改**：每张照片记录 SHA-256，电脑端归档脚本会逐一校验。
- **备份/恢复**：全量备份为 ZIP，换手机或清理浏览器前可恢复。

## 手机上使用

1. 用 **Chrome** 打开部署地址（见项目说明），不要用微信内置浏览器。
2. 右上角菜单 →「添加到主屏幕」，之后从桌面图标进入。
3. 首次使用允许「相机」「位置」权限。
4. 首页右上角上传按钮导入 `照片任务导入.csv`。
5. 点批次 → 点类别行 → 拍照；拍完点「提交锁定」。
6. 批次详情 →「导出本批次」→ 生成 ZIP → 分享到微信/保存到文件管理器。
7. 把 ZIP 传到电脑项目目录，运行：

```powershell
python tools\photo_ingest.py 你的文件.zip
```

照片会解压到 `照片归档/{批次号}/`，并自动核对六类照片、张数上限和 SHA-256。

## 本地运行 / 部署

本项目是**免构建**的静态站点，不需要 Node。

```powershell
# 在本目录启动本地服务（localhost 可调用相机）
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/
```

部署到任意 HTTPS 静态托管即可（GitHub Pages / Cloudflare Pages / Nginx）。`manifest.webmanifest`、`sw.js` 全部使用相对路径，可放在子目录下。

> 相机与定位要求 HTTPS（localhost 除外）。部署地址一旦变化，浏览器会视为新站点，旧数据不会带过去。

## 数据与限制

- 照片**只存本机**，不上传任何服务器；仓库里也没有业务数据。
- 清除浏览器站点数据、卸载浏览器、换手机都会导致照片丢失。**每周做一次全量备份，重要批次导出后立即归档。**
- 单类上限 10 张，导出时按类别内时间排序编号。
- 主目标为安卓 Chrome；iPhone Safari 也能用，但导出/打印体验略差。
- 图片默认长边 1600px、JPEG 85；可在设置改为 1280/2048 和 75/92。
